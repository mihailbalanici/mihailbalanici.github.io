Welcome to my new site! This first post doubles as a template.

## How to write a new post

1. Create a file in the `_posts` folder named `YYYY-MM-DD-short-title.md`.
2. Start it with a front-matter block like the one at the top of this file.
3. Write the rest in Markdown — headings, **bold**, lists, links, images and code all work:

```python
print("Telemetry in, insights out")
```

Commit the file and it appears on the [Blog](/blog/) page within a minute or two.
Delete this post whenever you like.
